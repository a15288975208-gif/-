# 维权打假工作台

一个支持 **注册登录、跨设备同步（服务端存储）**、项目卡片化管理、OCR识别、倒计时预警、外部链接跳转 的个人维权管理应用。

## 功能覆盖

- 新建/编辑维权项目（含你提出的字段，支持回填编辑）
- 工作台总览（项目总数、状态）
- 48小时倒计时预警（监管知晓日起7个工作日、立案回复日起N个工作日）
- 图片上传 + OCR：
  - 部门回复内容拍照识别并保存
  - 电商订单截图识别订单号与快递单号
- 外部网站链接模块（自定义名称+跳转）
- 账号注册登录（JWT），数据存于服务端 SQLite，支持多设备登录后查看同一数据
- 响应式界面，支持电脑/手机缩放查看
- 预留接口基础：EMS记录已建字段，后续可接入你提供的API

## 快速启动

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`

## 技术说明

- 后端：Express + SQLite（better-sqlite3）
- 鉴权：JWT
- 前端：原生 HTML/CSS/JS（卡片式引导录入）
- OCR：Tesseract.js（中英混合识别）

## 后续可继续扩展

- 对接你后续提供的 EMS / 电商平台 API
- 项目附件按项目归档
- 消息推送（短信/邮件/企业微信）
- 角色权限和审计日志
